# FutureYou MVP

**User:** a student deciding whether an internship requiring relocation fits their near-term cash flow.

**Decision:** take the internship, share housing, or stay with the current campus job.

**Success:** show the first cash shortfall and its cause, compare specific assumptions, and save a reproducible scenario. The key demonstration is a positive ending balance hiding an earlier negative balance.

Implemented: fictional profile; Nessie import; dated 90-day forecast; three financial indicators; live assumption controls; scenario comparison; ledger; CSV export; browser plan persistence; optional Atlas persistence; optional Gemini explanation; transparent calculation-method page.

Excluded: real bank authentication, payments, underwriting, investment recommendations, automated financial decisions, multi-user accounts, and arbitrary life-event planning. Keep the internship demo coherent before adding more scenario types.

Service activation is separate from implementation: Atlas needs a database user and runtime network access; Gemini needs an API key. Show their actual status in the product and submission.
