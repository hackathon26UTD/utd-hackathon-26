# Safe Home name and compatibility

Current as of November 8, 2026. Ayan requested **Safe Home** as the name across the website and organization documentation. Capitalize it exactly this way: two words, capital S and H. HomeBeacon is the former product name.

## Presentation

Use Safe Home in navigation, page titles, metadata, account/assistant setup, source labels, prepared email copy and first-party brand assets. November 8 follow-up: Ayan requested the colors, type character and logo arrangement of State Farm's Drive Safe & Save. Safe Home now uses warm red actions, white/charcoal surfaces, a red house and stacked SAFE/HOME lettering, while retaining the actual Argus components. This is a visual adaptation, not a new stack, insurance product or claim of sponsorship.

## Reference and type provenance

The reference is the [official Drive Safe & Save page](https://www.statefarm.com/insurance/auto/discounts/drive-safe-save) and the stacked typography in its [official setup leaflet](https://static1.st8fm.com/en_US/applications/dss-manager/1.0/resources/files/DSS_Mobile_NextSteps.pdf). State Farm's [public stylesheet](https://static1.st8fm.com/en_US/dxl-1x/prod/css/1x.core.css) uses Mecherle Sans and SF News Gothic and the red `#d62311`. No redistribution license for those custom fonts was established, so their font files are not bundled or hotlinked.

Safe Home uses the already-pinned **Hanken Grotesk Variable 5.3.0**, a matching open-source sans-serif rather than the exact State Farm font. Its SIL Open Font License is served at `/licenses/hanken-grotesk.txt`. Technical readouts retain Spline Sans Mono. The wordmark uses bold SAFE over regular HOME, with outlined glyphs to render identically before web fonts load. It is our house mark and product name, not State Farm's name or three-oval emblem. Existing independent-project wording remains in Terms.

Primary actions: `#d62311`, hover `#a11b13`, white text. Body: `#212121` on `#f7f7f7`/white. Dark surfaces: `#171717`/`#202020`, light red links. Sensor normal/caution/critical/unknown colors and their meanings are unchanged. Red actions do not classify device readings.

Shared branding lives in `ui/brand.js` and `ui/brand.css`. Outlined logo variants and favicon are generated by `scripts/build-wordmark.py` using the existing font package and authoring-only `fonttools[woff]`; the committed SVGs need no Python at build/runtime. Run `node ui/kit/tools/make-theme.mjs` after token changes and `node scripts/build-brand-assets.mjs` after share-card changes. Do not edit vendored Argus sources.

The checked-in share card is `public/social-preview.png`; its source is `ui/brand/social-card.html`. Regenerate it with `node scripts/build-brand-assets.mjs`, then build. The old JPEG is historical and no longer referenced by active page metadata. The compatibility-named SVG wordmark files now draw Safe Home.

## Stable technical names

Do not change these as a text cleanup:

- GitHub organization/repository, Cloudflare project, production URL and MongoDB database.
- Existing API routes, device IDs, cookies, session-signing labels, OAuth scopes and MCP tool names.
- Local-storage keys, simulation export schema identifiers, audit names and provider request identifiers.
- `window.HomeBeaconKit`, CSS/file paths containing `homebeacon`, and `clients/esp32/HOMEBEACON.md`.
- `X-HomeBeacon-Data`, an existing synthetic-response header.

Renaming those is a separate migration with compatibility and security consequences. Existing profiles, paired boxes, assistant connections and shared links must keep working after this release. User-entered device names and historical records are not rewritten in the database.

## Documentation rules

Current entry-point and product docs use Safe Home. Historical worklogs, dated handoffs, screenshots, provenance and older contract filenames retain their original names for traceability. Do not rewrite past evidence to imply the project always had the new name. Vendor/third-party notices and teammate attribution are unchanged. [Rename decision](decisions/0001-safe-home-name.md).
